# İstanbul'da Kiralık Konut Fiyat Tahmini

İstanbul kiralık konut ilanları üzerinden fiyat tahmini yapmayı amaçlayan takım projesi. Keşifsel veri analizi, ön işleme ve modelleme adımlarını kapsar.

**Durum:** 🚧 Dokümantasyon tamamlandı — analiz kodu depoya eklenecek.

## İçerik

| Dosya | Açıklama |
|---|---|
| `Ön İşleme ve Keşifsel Veri Analizi Raporu.docx` | Veri temizleme adımları ve EDA bulguları |
| `Görselleştirme, Yorumlama ve Tartışma Belgesi.docx` | Grafikler, model çıktılarının yorumu ve tartışma |
| `Etik Tefekkür Belgesi.docx` | Veri kaynağı ve model kullanımına dair etik değerlendirme |
| `Takım_1.pptx` | Proje sunumu |

## Eksikler

- [ ] Analiz not defterinin (`.ipynb`) depoya eklenmesi
- [ ] Kullanılan veri setinin veya erişim bilgisinin paylaşılması
- [ ] Model kodunun ve değerlendirme metriklerinin ayrı dosyalara çıkarılması
- [ ] Raporların Markdown'a dönüştürülmesi
